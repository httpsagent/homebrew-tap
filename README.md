# HttpsAgent Homebrew Tap

Homebrew formula for [HttpsAgent](https://github.com/httpsagent/httpsagent) on macOS and Linux.

```sh
brew install httpsagent/tap/httpsagent
```

The full name adds this tap and trusts only the `httpsagent` formula (Homebrew 6 requires trust for taps outside Homebrew). After that, the short name works:

```sh
brew upgrade httpsagent
brew uninstall httpsagent
```

The formula is generated by each release; please open issues in [httpsagent/httpsagent](https://github.com/httpsagent/httpsagent/issues).
